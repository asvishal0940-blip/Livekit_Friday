# Friday VA

A sophisticated voice AI assistant inspired by Friday from Iron Man. An intelligent personal assistant that handles automation, scheduling, web search, email management, and more.

## Features

- **Voice Interface**: Natural language conversation with voice input/output
- **Automation**: Execute tasks and automate workflows
- **Task Management**: Create and manage events and reminders
- **Web Search**: Real-time information retrieval
- **Email Integration**: Send and manage emails
- **Memory System**: Contextual memory of previous conversations
- **MCP Integration**: Support for Model Context Protocol servers
- **Multi-modal AI**: Powered by Deepgram STT, Google Gemma LLM, and Inworld TTS

## Installation

```bash
git clone https://github.com/asvishal0940-blip/Friday_va.git
cd Friday_va
pip install -r requirements.txt
```

## Usage

```bash
python agent.py
```

## Configuration

Configure Friday by editing the `.env` file in the root directory with your API keys and preferences.
